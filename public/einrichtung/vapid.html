Push-Schlüssel erzeugen

Für StudySpace-Benachrichtigungen brauchst du einmalig ein VAPID-Schlüsselpaar und ein Scheduler-Secret. Die Werte werden nur hier in deinem Browser erzeugt und nirgendwohin gesendet.

Den privaten Schlüssel und das Secret niemals auf GitHub, in die App oder in Chats kopieren.

  1. VAPID_PUBLIC_KEY → GitHub: Settings → Secrets and variables → Actions → Variables → VITE_VAPID_PUBLIC_KEY
  2. Alle drei Werte + VAPID_SUBJECT (z. B. mailto:eure@adresse.de) → Supabase: Edge Functions → Secrets
  3. SCHEDULER_SECRET zusätzlich in supabase/cron.sql einsetzen (nur im SQL Editor, nicht im Repository speichern)

Diese Seite danach schließen. Die Werte werden nicht gespeichert.
